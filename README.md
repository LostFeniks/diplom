# Развёртывание проекта

## 1. Назначение

Проект представляет собой веб-приложение файлового хранилища.

Для запуска проекта необходимо установить:

* Python 3.13;
* PostgreSQL 17 или выше;
* Node.js и npm.

Все остальные зависимости устанавливаются из файлов проекта.

Инструкция рассчитана на развёртывание проекта в операционной системе Windows с использованием PowerShell.

---

## 2. Получение проекта

Склонировать репозиторий:

```powershell
git clone <АДРЕС_РЕПОЗИТОРИЯ>
```

Перейти в каталог проекта:

```powershell
cd diplom
```

Структура проекта:

```text
diplom/
├── backend/
├── frontend/
├── .env.example
├── .gitignore
└── README.md
```

---

## 3. Установка и настройка PostgreSQL

Установить PostgreSQL версии 17 или выше.

После установки необходимо создать базу данных и пользователя приложения.

Подключиться к PostgreSQL:

```powershell
psql -U postgres -h localhost -p 5432
```

После подключения выполнить:

```sql
CREATE USER admin WITH PASSWORD 'admin';
```

Создать базу данных:

```sql
CREATE DATABASE diplom OWNER admin;
```

Предоставить пользователю права на базу данных:

```sql
GRANT ALL PRIVILEGES ON DATABASE diplom TO admin;
```

Выйти из PostgreSQL:

```sql
\q
```

Если пользователь `admin` или база данных `diplom` уже существуют, повторно создавать их не требуется.

Проверить подключение к созданной базе:

```powershell
psql -U admin -h localhost -p 5432 -d diplom
```

---

## 4. Настройка переменных окружения

В корне проекта находится файл `.env.example`.

Необходимо создать на его основе файл `.env`:

```powershell
Copy-Item .env.example .env
```

Открыть файл `.env` и указать параметры подключения к PostgreSQL:

```env
DB_NAME=diplom
DB_USER=admin
DB_PASSWORD=admin
DB_HOST=localhost
DB_PORT=5432

DJANGO_SECRET_KEY=change-this-secret-key
DJANGO_DEBUG=True
```

`DJANGO_SECRET_KEY` необходимо заменить на произвольную строку, используемую в качестве секретного ключа Django.

Файл `.env` используется только локально и не должен загружаться в репозиторий.

---

# 5. Развёртывание серверной части

Перейти в каталог backend:

```powershell
cd backend
```

Создать виртуальное окружение Python:

```powershell
python -m venv venv
```

Активировать виртуальное окружение:

```powershell
.\venv\Scripts\Activate.ps1
```

Если PowerShell запрещает выполнение скриптов, выполнить:

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
```

После этого снова выполнить:

```powershell
.\venv\Scripts\Activate.ps1
```

Установить зависимости проекта:

```powershell
pip install -r requirements.txt
```

---

## 6. Настройка базы данных Django

После установки зависимостей необходимо выполнить миграции:

```powershell
python manage.py migrate
```

Проверить конфигурацию проекта:

```powershell
python manage.py check
```

При корректной настройке должен появиться результат:

```text
System check identified no issues
```

---

## 7. Создание администратора

Для создания административного пользователя выполнить:

```powershell
python manage.py seed_admin
```

После выполнения команды будет создан или настроен пользователь-администратор.

Данные для первоначального входа:

```text
Логин: admin
Пароль: Admin123!
```

После первого входа пароль рекомендуется изменить.

---

## 8. Запуск серверной части

Запустить Django-сервер:

```powershell
python manage.py runserver
```

После успешного запуска сервер будет доступен по адресу:

```text
http://127.0.0.1:8000/
```

Окно PowerShell с работающим Django-сервером необходимо оставить открытым.

Для остановки сервера используется сочетание клавиш:

```text
Ctrl + C
```

---

# 9. Развёртывание клиентской части

Открыть **новое окно PowerShell**.

Перейти в каталог frontend:

```powershell
cd frontend
```

Установить зависимости:

```powershell
npm install
```

После завершения установки запустить приложение:

```powershell
npm run dev
```

Vite выведет адрес запущенного приложения, обычно:

```text
http://localhost:5173/
```

---

# 10. Проверка работы приложения

Открыть в браузере:

```text
http://localhost:5173/
```

Для полноценной работы должны быть одновременно запущены:

1. PostgreSQL;
2. Django-сервер;
3. React/Vite-сервер.

---

# 11. Проверка основных функций

После запуска необходимо проверить:

### Регистрация

Открыть страницу регистрации и создать нового пользователя.

Необходимо указать:

* логин;
* ФИО;
* адрес электронной почты;
* пароль.

После успешной регистрации выполнить вход.

### Вход

Войти под созданным пользователем.

Обычный пользователь должен получить доступ только к собственному файловому хранилищу.

### Работа с файлами

В файловом хранилище проверить:

* загрузку файла;
* добавление комментария;
* отображение имени файла;
* отображение размера;
* отображение даты загрузки;
* скачивание файла;
* изменение имени файла;
* изменение комментария;
* создание публичной ссылки;
* удаление файла.

### Администрирование

Войти под административным пользователем:

```text
Логин: admin
Пароль: Admin123!
```

В административном интерфейсе проверить:

* просмотр списка пользователей;
* просмотр регистрационных данных;
* изменение признака администратора;
* удаление пользователя;
* просмотр количества файлов пользователя;
* просмотр общего размера файлов;
* переход к файловому хранилищу выбранного пользователя.

# 16. Важная информация о конфиденциальных данных

Файл `.env` содержит параметры подключения к базе данных и секретный ключ Django.

Он не должен передаваться другим пользователям и не должен размещаться в GitHub.

В репозитории должен находиться только файл:

```text
.env.example
```

с примером необходимых переменных без реальных секретных данных.

Файл `.gitignore` содержит правило:

```text
.env
```

что предотвращает добавление локального файла `.env` в Git-репозиторий.
